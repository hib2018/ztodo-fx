# TUI Contract

- `m`: 管理メニューを開く
- `Tab` / `Shift-Tab`: 通常時はペイン、メニュー時はProposal/Repository/Issueタブを切替
- `j` / `k`, arrows: 選択またはDetails表示行scroll
- `g` / `G`: Details先頭／末尾
- `Enter`: tree展開、menu項目実行
- `Esc`: modal取消

Issue menuはrefresh、details、open in GitHub、show/hide closedを提供する。Closed表示は既定off。通常画面からProposalとRepositoryの直接shortcutは除き、menu内に案内する。
